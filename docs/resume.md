# InsureClear – Resume Highlights

- Developed **InsureClear**, a GenAI-powered insurance assistant using Python, FastAPI, Streamlit, and RAG to answer user questions using official IRDAI insurance information.

- Implemented semantic search with ChromaDB and integrated Groq/Gemini LLMs to generate context-aware answers with relevant source references.

- Improved application reliability with LRU response caching (128-entry capacity), input validation, prompt-injection protection, latency and token monitoring; added Pytest tests, Ruff checks, Docker support, and Render deployment.
